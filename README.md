# EBay Order Management PHP SDK

PHP SDK for eBay Order Management APIs, combining REST and GraphQL clients.

## Covered APIs

- **Fulfillment V1** — orders, line items, shipping fulfillment
- **Logistics V1** — shipping quotes and shipment creation
- **GraphQL** — order and fulfillment queries

## Specs

OpenAPI specs and GraphQL schema are in `specs/`. Implementation not yet started.
